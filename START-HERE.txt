حزمة فحص TrustSoft / Jawafa_DB — قراءة فقط

1) حمّل ZIP وفكّه بالكامل في C:\TrustSoftCheck على السيرفر JAWAFFASVR.
   لا تشغّله من داخل ZIP ولا تضعه داخل C:\Export.
2) شغّل Run-TrustSoftCheck.cmd بالنقر مرتين.
   استخدم حساب Windows مصرحًا له بقراءة Jawafa_DB.
   لا تحتاج تشغيله كمسؤول لمجرد الاتصال بقاعدة البيانات.
3) انتظر حتى تظهر REPORT ZIP. عادةً يستغرق الفحص أقل من دقائق،
   لكن المدة تعتمد على استجابة الخادم وعدد عناصر المخطط.
4) سيُنشأ مجلد reports وبداخله ملف TrustSoft-<وقت>-<معرّف>.zip.
   أرسل ملف النتيجة هنا؛ قول «تم» وحده لا يبيّن هل نجح SQL.
   إذا لم يتكوّن ZIP أرسل summary.json وsql.json وserver.json من مجلد التقرير.
   إذا لم يتكوّن مجلد reports أرسل صورة الخطأ الظاهر بدل إعادة التشغيل عشوائيًا.

الحزمة لا تغيّر بيانات أو خدمات أو مهام مجدولة، ولا توقف أو تبدأ التصدير،
ولا تنسخ محتويات CSV أو سجل run.log أو كلمات مرور.
يُحفظ كل تشغيل في مجلد جديد، ولا تُحذف تقارير سابقة.
النتائج تحتوي أسماء مخطط واسم حساب ومعلومات تشغيل؛ أرسلها في هذه المحادثة الخاصة فقط.

الحساب:
الاتصال الحالي يستخدم Windows Integrated Authentication؛ لا يطلب كلمة مرور SQL.
حساب Administrator قد يملك صلاحيات كتابة ويؤدي إلى read_only_principal_required.
هذا ليس سببًا لتوسيع الأذونات؛ نحتاج هوية قراءة مصرحًا بها.
إذا كان الحساب SQL-only، نفّذ التشخيص المتاح وأرسل التقرير؛ لا تكتب كلمة المرور بالمحادثة.

ماذا تعني النتيجة؟
SQL READ VERIFIED = نجح اتصال وقراءة هوية ومخطط القاعدة في هذه المحاولة فقط.
SQL READ NOT VERIFIED = يوجد عائق؛ تقرير JSON يحمل المرحلة ورموز الخطأ لتحديد الإصلاح.
نجاح الفحص لا يثبت مطابقة البيانات المالية أو اتصال لوحة التحكم بعد.
حالات unavailable ببعض فحوص Windows تعني حدود رؤية الحساب أو غياب مكوّن،
ولا تثبت أن الخدمة أو العملية غير موجودة.

إذا كان SQL على مثيل مسمى تعرفه مسبقًا، افتح PowerShell من مجلد الحزمة وشغّل:
.\Run-TrustSoftCheck.ps1 -Server 'JAWAFFASVR\اسم_المثيل_الحقيقي'

إذا منعت سياسة PowerShell التشغيل، أرسل صورة الرسالة؛ لا تعطّل سياسة الجهاز.
الحزمة لا تستخدم ExecutionPolicy Bypass ولا تعطل TLS أو تحقق الشهادات.
إذا رفضت شهادة SQL، سنعالج الثقة بالاعتماد على النتيجة دون تعطيل التحقق.

متطلبات التشغيل: Windows PowerShell 5.1 و.NET المدمج. لا Python ولا تنزيلات مطلوبة.
حُققت سلامة تغليف الحزمة محليًا؛ تنفيذها على Windows واتصال SQL لم يُختبرا هنا.
