# نتيجة فحص قناة الخادم — 27 أكتوبر 2026

فحص الويب الحي نجح: دخول الإدارة HTTP 200، ومسار التحاق الوكيل HTTP 200 بمفتاحه الحالي.
فحص التحاق الوكيل لم يرسل heartbeat أو نتيجة SQL باسم الخادم.
حالة الخادم الفعلية بقيت online=false وlast_seen=null؛ طلبات إعادة الاتصال السابقة انتهت دون تنفيذ.

معلومات SQL المرفقة تحدد JAWAFFASVR وJawafa_DB ودخول sa. لم يصل فحص السحابة إلى مصادقة SQL:
الاسم المحلي غير محلول، والجسر القديم HTTP على 3456 أعاد403، ولا يوجد VPN أو تصريح TCP مهيأ.
جرى فحص حساب Cloudflare المستخدم للوحة للقراءة فقط؛ عدد الأنفاق غير المحذوفة صفر.
أداة Desktop Commander وخدمة تنفيذ Windows عن بعد غير متاحتين في أدوات هذه الجلسة.
لا تثبت هذه النتائج توقف SQL أو فساد كلمة المرور أو عدم تثبيت الوكيل؛ يلزم دليل من المضيف نفسه.

## الإصلاحات المتاحة

تعرض لوحة الويب الآن «بانتظار أول اتصال من الخادم» عندما لا يوجد سجل اتصال،
وتوضح أن تنفيذ الطلب يحتاج تشغيل الوكيل. جرى نشر هذا التغيير والتحقق من الدخول والحالة
بمتصفح Chromium ومحاكاة Android، دون تزوير اتصال خادم أو تشغيل فحص إنتاج.

أصلح كود الوكيل مسارًا كان يمكن أن يمنع استئناف poll: نتيجة outbox يرفضها الخادم بـ413
أو ملف نتيجة تالف. يحفظ الأصل في history، ويرسل تقرير فشل صغيرًا بالطلب نفسه عند توافر
هوية موثوقة في running.json، دون إعادة تشغيل الفحص. يبقى رفض المصادقة أو اختلاف broker مانعًا للتسليم.
تُسجل أسباب ثابتة وأرقام HTTP في data\agent-events.jsonl دون نصوص أخطاء خام أو مفاتيح أو عناوين.
استُبدل حساب وقت Unix ليتوافق مع إصدارات .NET الأقدم.

اختبارات التعافي تستخدم دوال الوكيل نفسها وHTTP في الذاكرة وبيانات مصطنعة فقط.
لم يُوزع هذا الإصلاح على JAWAFFASVR أو يُشغّل على Windows من هذه الجلسة.
لا يجوز اعتباره استعادة اتصال الإنتاج أو إثبات نجاح SQL.

## الإجراء التقني المتبقي

يلزم تنفيذ معتمد داخل الخادم: تشغيل الوكيل لأول مرة، أو فحص المهمة والنسخة والسجل إن كان مثبتًا.
الحزمة والتعليمات في [دليل Windows](UPLOADED-SQL-CHECK.md). يحافظ المثبت على أي تثبيت موجود؛
لا يُحذف أو يُستبدل مجلد ProgramData\TrustSoftAgent أو config أو DPAPI أو data/history تلقائيًا.
بعد توافر قناة إدارة معتمدة لهذه الجلسة يمكن فحص المضيف نفسه، ثم اختبار heartbeat واستعلام SQL
الحقيقي والتعافي الآمن. لا تُغيّر بيانات TrustSoft أو خدمات SQL أو الصادرات لإصلاح قناة الوكيل.
