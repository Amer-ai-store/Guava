TrustSoft — المسار المجاني الحالي

ابدأ بقراءة docs/FREE-HOSTING.md.
الاستضافة الحالية المستهدفة Cloudflare Workers + D1 بخطة مجانية وحدود محددة،
مع بيانات طلبات دائمة. لا تستخدم ملف Render المدفوع لهذا المسار.
الواجهة ويب؛ تُفتح برابط HTTPS فعلي بعد النشر، وليس بفتح هذه الملفات على الهاتف.

المطلوب: حساب Cloudflare مجاني ومفتاح نشر في حقل الأسرار الموجود CLOUDFLARE_API_TOKEN.
لا ترسل المفتاح بالمحادثة. نطاق المفتاح api.cloudflare.com فقط.
بعد حفظ إعدادات البيئة وتطبيقها:
    cd deploy/cloudflare
    npm ci
    cd ../..
    python -m scripts.deploy_cloudflare

لا يبدأ الناشر خطة مدفوعة، ولا يعلن النجاح قبل اختبار الرابط الفعلي والدخول وD1.
يثبت وكيل Windows مرة واحدة على JAWAFFASVR بالعنوان الناتج ومفتاح الوكيل الخاص.
لا حاجة لفتح AnyDesk في كل مرة بعد تثبيت الوكيل وإثبات اتصال SQL الحقيقي.

اختبارات المصدر:
    python -m scripts.verify
    python -m scripts.check_free_worker

التخزين المحلي للمختبر وبيانات SQL الاصطناعية ليسا دليل استضافة عامة أو اتصال إنتاج.
لم يتوفر مفتاح Cloudflare في الجلسة عند إنشاء هذه الحزمة؛ الموقع لم يُنشر بعد.
